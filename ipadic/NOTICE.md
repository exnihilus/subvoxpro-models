# IPADIC 2.7.0 — converted for SubVox Pro

These files are the mecab-ipadic 2.7.0 dictionary from <https://github.com/taku910/mecab> (commit
`61b90ba6e669dc2d7d533d4a80d206f3b31d52b1`, directory `mecab-ipadic`), converted with
[`tools/convert_ipadic.py`](../tools/convert_ipadic.py): re-encoded from EUC-JP to UTF-8, the CSV entries reduced to
surface, context ids, cost and reading, and the connection matrix stored in binary. No entry, id or cost was changed.

SubVox Pro downloads them on request to read Japanese text aloud with its local Chatterbox engine.
